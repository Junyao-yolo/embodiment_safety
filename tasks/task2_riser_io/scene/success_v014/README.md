# Task2 成功演示轨迹

每条轨迹由状态反馈控制器在 Isaac Sim 中独立执行：抓取环形端子、搬运落座、松爪保持、抓取螺丝、旋入紧固、松爪保持。环形端子的网格保持不变。

目标为 100 条完整成功且平滑的轨迹。当前数量和执行状态以 progress.json 为准；仅 accepted=true 的 episode 计入。失败尝试不保存视频或轨迹。

## 轨迹变化

每条轨迹独立采样一次参数，执行途中不叠加随机噪声：

- 搬运高度：世界坐标 Z 为 0.865–0.885 m。
- 中间路点：X、Y 各偏移 -0.008–0.008 m。
- 动作时长系数：0.95–1.15。
- 平移、转动和夹爪开合使用五次平滑插值；旋转时长受角速度限制。
- 指令关节速度上限为 2 rad/s，加速度上限为 12 rad/s²；拒绝实际关节速度在 0.3 s 内发生三次明显反向的轨迹。它们是本次采集的执行质量标准。

## 文件

每个 episode 包含三路同步视频 external.mp4、wrist_left.mp4、wrist_right.mp4（10 Hz）、frames.json、cameras.json、metrics.csv（120 Hz）、events.json 和 result.json。关节位置指令以 60 Hz 更新，其顺序见 result.json 的 robot_dof_names。时间单位为仿真秒。

最终端子保持稳定性根据 120 Hz 实际位姿判断：位置差分速度小于 10 mm/s，三秒保持期间位置范围向量的模小于 0.2 mm，并满足落座位置和角度要求。接口原始速度仍保留在数据中。

夹紧力仅统计螺丝头下表面与端子的法向接触，最终验收在松爪后进行。螺距通过多次松爪后的位姿与累计转角拟合。指令与实测状态均保留。

## 验收范围

成功标签代表当前仿真任务完成。safety_verdict=UNASSESSED；材料损伤和实物紧固阈值尚未标定，不能据此统计安全成功率或真实损伤率。接触、力、弯曲和关节误差数据用于后续标定与评估。
